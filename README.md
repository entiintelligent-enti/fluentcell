# FluentCell

Batarya test mühendisi için günlük İngilizce konuşma koçu. Hedef: iş toplantılarında anlayıp cevap verebilmek.

Tek dosya (`index.html`), sunucu gerekmez. GitHub Pages üzerinden telefonda açılır.

## Neler var
- **Bugün:** 60 dakikalık günlük plan, şarj göstergesi (SoC), seri takibi. 4 haftalık konu döngüsü.
- **Kartlar:** Aralıklı tekrar (Anki mantığı), 48 hazır toplantı kalıbı, kendi kartların.
- **Video:** Dinleme ve shadowing yönergeleri, haftalık kaynak önerileri.
- **Konuş:** Günün konusu, hata defteri.

## Gemini özellikleri
- Konuşmanı düzelt: hatalar, doğal söyleyiş, ezberlenecek kalıplar
- Toplantı simülasyonu: müdür, tedarikçi, müşteri, iş görüşmesi
- Durumuna özel kart üretme
- Anlamadığın cümleyi çözme

Anahtar: https://aistudio.google.com/apikey adresinden al, uygulamada ⚙ Ayarlar'a yapıştır.
Anahtar sadece tarayıcının yerel deposunda tutulur, bu depoya yazılmaz.

## Veriler
İlerleme tarayıcıda (localStorage) saklanır. Ayarlar → Yedeği indir / Yedekten yükle.

## Telefona kurma
Sayfayı Chrome'da aç → menü → Ana ekrana ekle (iPhone'da Safari → Paylaş → Ana Ekrana Ekle).
